# Security Dashboard

React + Vite SPA that displays security scan results with Material UI and Apache ECharts visualization.

## Architecture

- **Client-side only** (SPA mode): No SSR, all data loaded via `fetch()`
- **Data source**: Static `/data/` directory (generated by GitHubPagesBuilder.java)
- **UI Framework**: Material UI + Apache ECharts for trend visualization
- **Routing**: React Router v7
- **Validation**: Zod schemas for runtime JSON validation
- **Routes**:
  - `/security-scans` - Main dashboard with multi-channel security trends chart
  - `/security-scans/channel/:channel` - Channel-specific scan list
  - `/security-scans/channel/:channel/run/:timestamp` - Individual scan details (Trivy + Semgrep)

## Development

### Quick Start (Makefile)

```bash
# From project root
make dashboard-dev           # Start dev server at http://localhost:5173
make dashboard-build         # Build production assets
make dashboard-test-data     # Generate realistic 20-day test scan history
make dashboard-clean         # Clean build artifacts

# Or from dashboard/ directory
cd dashboard
make              # Show all available commands
make dev          # Start dev server
make test-data    # Generate test data
```

### Manual Commands

```bash
npm install
npm run dev       # Dev server at http://localhost:5173
npm run build     # Production build → dist/
npm run preview   # Preview production build
```

## Test Data

Generate realistic scan history showing security improvement over time:

```bash
make test-data
# Creates public/data/hist/scan-history.json with:
# - Days 1-10: High vulnerabilities (C:10, H:25)
# - Day 11: Major fix applied (C:0, H:8)
# - Days 12-20: Gradual improvement → zero
```

## Why Client-Side Only?

**Benefits**:
- Zero deployment complexity (just static files)
- No server costs or maintenance
- Works on any static file host (GitHub Pages, S3, CDN)
- Fast dev experience with Vite HMR

## Build

```bash
npm run build
# Output: dist/ (static assets for GitHub Pages)
```

## Integration

The `actions/builder/dashboard/action.yml` will:
1. Build this React app (`npm run build`)
2. Upload `dist/` as artifact
3. GitHubPagesBuilder merges this with `/data` directory
4. Final package deployed to GitHub Pages
