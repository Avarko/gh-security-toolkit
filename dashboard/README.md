# Security Dashboard

React+Remix SPA that displays security scan results with Material UI and Apache ECharts visualization.

## Architecture

- **Client-side only** (SPA mode): No SSR, all data loaded via `fetch()`
- **Data source**: Static `/data/` directory (generated by GitHubPagesBuilder.java)
- **UI Framework**: Material UI (dark theme) + Apache ECharts for trend visualization
- **Routes**:
  - `/` - Main dashboard with multi-channel security trends chart (reads `/data/hist/scan-history.json`)
  - `/data/channels/:channel` - Channel-specific scan list
  - `/data/runs/:channel/:timestamp` - Individual scan details (Trivy + Semgrep)

## Development

### Quick Start (Makefile)

```bash
# From project root
make dashboard-dev           # Start dev server at http://localhost:5173
make dashboard-build         # Build production assets
make dashboard-test-data     # Generate realistic 20-day test scan history
make dashboard-clean         # Clean build artifacts

# Or from dashboard/ directory
cd dashboard
make              # Show all available commands
make dev          # Start dev server
make test-data    # Generate test data
```

```bash
npm install
npm run dev       # Dev server at http://localhost:5173
npm run build     # Production build → build/client/
npm run preview   # Preview production build
```

## Why the Client-Side Only Architecture?

**Problem**: Remix defaults include SSR (server-side rendering) which requires Node.js server.

**Our Solution**:
- `ssr: false` in vite.config.ts → Pure SPA
- `clientLoader()` functions fetch JSON via `fetch()` API
- No `@remix-run/node` imports (browser-incompatible)
- No server runtime needed → Perfect for GitHub Pages static hosting

**Benefits**:
- ✅ Zero deployment complexity (just static files)
- ✅ No server costs or maintenance
- ✅ Works on any static file host (GitHub Pages, S3, CDN)
- ✅ Fast dev experience with Vite HMR

## Build

```bash
npm run build
# Output: build/client/ (static assets for GitHub Pages)
```

## Integration

The `.github/workflows/actions/dashboard/action.yml` will:
1. Build this Remix app (`npm run build`)
2. Upload `build/client/` as artifact
3. GitHubPagesBuilder merges this with `/data` directory
4. Final package deployed to GitHub Pages
