# Security Dashboard

React+Remix SPA that reads `/data` JSON files and displays security scan results.

## Architecture

- **Client-side only** (SPA mode): No SSR, all data loaded via `fetch()`
- **Data source**: Static `/data/` directory (generated by GitHubPagesBuilder.java)
- **Routes**:
  - `/` - Main dashboard (reads `/data/hist/scan-history.json`)
  - `/data/channels/:channel` - Channel-specific scan list
  - `/data/runs/:channel/:timestamp` - Individual scan details (Trivy + Semgrep)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
# Output: build/client/ (static assets for GitHub Pages)
```

## Integration

The `.github/workflows/actions/dashboard/action.yml` will:
1. Build this Remix app (`npm run build`)
2. Upload `build/client/` as artifact
3. GitHubPagesBuilder merges this with `/data` directory
4. Final package deployed to GitHub Pages
